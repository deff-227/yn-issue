[알림과 메시지 관리]
알림창은 상단 시간을 눌러 연다. '모두 지우기'는 도착해 있는 알림만 삭제한다.
'알림 끄기'는 새 알림 표시를 중단할 뿐, 앱 내 대화/기사/문자/메일을 지우지 않는다.
이야기 시각, 읽음 상태, 작성한 메시지 등 진행 기록은 localStorage로 보존된다.
새로고침 후 진행 상태가 유지된다. 설정 > 처음부터 다시 시작에서만 초기화한다.

[GitHub Pages 배포]
1. 신규 GitHub 저장소를 만든다. 기존 yeopne, yeopne_yc 저장소는 그대로 둔다.
2. ZIP 내부 index.html, styles.css, app.js, README 파일을 저장소 루트에 업로드한다.
3. 저장소 Settings > Pages > Build and deployment > Deploy from a branch 선택.
4. main / (root) 지정 후 Save.
5. 생성된 https://<계정>.github.io/<저장소>/ 주소로 접속한다.

[소스와 한계]
원본 사이트 after-the-encore.sirimu.chatgpt.site의 소스에는 접근할 수 없어
사용자가 제공한 설정 및 기존에 제작했던 복구본 소스를 기반으로 재구성했다.
갤러리·SNS 이미지 일부는 GitHub 공개 저장소 deff-227/yeopne의 이미지 URL을 불러온다.
이미지 네트워크 접근이 차단되면 로드되지 않을 수 있다.
문자로 전달된 사진 3장과 기사 이미지는 원본이 없는 관계로 그래픽 썸네일로 표시한다.
기사, 댓글 및 기자의 연락 내용은 창작물의 시뮬레이션 대사이다.
실제 SNS·메일 서버의 계정을 사용하거나 실시간으로 메시지를 전송하지 않는다.
